# Contact Converter - GitHub APK Build

Built by Asad Biswas

## Build from mobile with GitHub
1. Extract this ZIP.
2. Create a new GitHub repository.
3. Upload all files and folders from the extracted project.
4. Open the Actions tab.
5. Run **Build Contact Converter APK**.
6. After the build succeeds, download the artifact named:
   `ContactConverter-AsadBiswas-APK`
7. Extract it and install `app-debug.apk`.

The workflow also runs automatically when changes are pushed to the `main` branch.
